# StockSync — product facts (approved for use in emails)

## What it does

- Keeps inventory counts in sync across sales channels. A sale or return on any
  connected channel updates the others within about one minute.
- Pulls orders from every channel into one list, so a seller fulfils from one
  screen instead of one per marketplace.
- Low-stock alerts per product and per channel.

## Supported channels

Shopee, Lazada, TikTok Shop, Shopify, WooCommerce.

Not supported today: Amazon, eBay, offline point-of-sale systems. Do not promise
support for them; say it is not available today and offer to note the request.

## How setup works

- Connecting a channel takes a few minutes (the seller authorises StockSync in
  the marketplace's own seller centre).
- Most sellers are fully set up within one working day, including the first
  product mapping across channels. No developer is needed.
- Existing stock counts are imported from the seller's current main channel.

## Customer story (approved)

Hanoi Fashion Chain, which sells on Shopee, Lazada and its own Shopify store,
went from several overselling incidents a month to none in its first two months
using StockSync.
